# Zaid Ahmad — Product & AI Engineer Portfolio

A high-performance, minimalist portfolio designed to showcase the intersection of product design, software engineering, and AI-powered systems. This application focuses on "calm technology" and intuitive interactions, mirroring Zaid Ahmad's philosophy of building trustworthy autonomous systems.

## 🚀 Overview

This portfolio is built with a focus on motion design and structural clarity. It highlights experience in building end-to-end AI products, creative distribution, and human-centric software.

### Key Sections
- **01 — Approach**: Background in creative ecosystems and scaling businesses from 0 to profit.
- **02 — Works**: Selected projects showcasing technical and design depth.
- **03 — Philosophy**: Perspectives on AI as interactive systems rather than just logic.
- **04 — Skills**: Comprehensive stack ranging from AI dev tools to platform integrations.
- **05 — Connect**: Direct channels for professional inquiries and social presence.

## 🛠 Tech Stack

- **Frontend**: React 18+ with TypeScript
- **Styling**: Tailwind CSS
- **Animation**: Framer Motion (`motion/react`)
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Deployment**: AI Studio / Google Cloud Run

## 🎨 Design Principles

- **Minimalist Aesthetic**: Dark-mode focused with high-contrast typography.
- **Motion-First**: Staggered entrances and smooth transitions using `AnimatePresence`.
- **Responsive Geometry**: Mobile-optimized layouts with custom-built navigation.
- **Interface Trust**: Glassmorphism and subtle glows to reduce "interface hesitation."

## 🏗 Setup & Development

To run this project locally:

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```
